# v0.1 developer preview

Status: open-source developer preview. The source distribution is a
developer-operated application; it is not a promise of free hosted generation
or production-ready multi-user hosting.

## Scope

The acceptance target is macOS arm64, Python 3.12, Node 22, pnpm 10.18,
Codex CLI and Godot 4.6 with matching Web export templates. Start with the
[setup guide](../guides/setup.md) and connect your own provider at `/connect`.
Personal provider setup has a [separate verification report](2026-11-10-personal-provider.md).
Create a small procedural game, play its Web
export, request one edit, and inspect the actual Godot source in the local games
directory. Use a zero paid-asset budget.

Claude, Bevy, voice and the separate agent-play prototype remain
available as experimental code. Their presence does not establish a validated
provider/engine matrix. Phoenix is an optional local operator dashboard with
its own license and installation. Existing provider selections are not changed
by the release; the example configuration recommends Codex.

## Distribution

Original source is Apache-2.0; original prose is CC BY 4.0. Upstream code and
fonts retain their notices. Read [licensing](../../LICENSING.md) and
[attribution](../../ATTRIBUTION.md). The candidate includes source and notices,
not Python/npm installations, engine/CLI binaries, Docker images, model weights,
private Git history, accounts, generated games or uploaded assets.

The initial release uses a reviewed source snapshot in a new history. Optional
development instructions with unresolved provenance are excluded only from that
snapshot; local skill availability and experiment records are preserved.

## Release acceptance

- [x] Prepare a source review candidate with a per-file manifest and public-link checks.
- [x] Install dependencies in a fresh environment; record resolved versions.
- [x] Run backend checks, frontend checks/typecheck/build and browser acceptance.
- [x] Create and edit one real Codex/Godot game from an empty database.
- [x] Scan the source review package; triage every finding without publishing secrets.
- [x] Limit distribution to source and notices; disclose eleven dependency notice collection gaps.
- [x] Exclude private history and generated assets; historical credential revocation remains a separate private task.

Repository checks and current verification are recorded in the
[publication report](2026-11-20-publication.md).

Test evidence is scoped to the manifest checked. A startup screenshot does not
prove game quality, and a working local setup does not establish hosted safety.
This release publishes source; it does not certify every generated game or
include a marketing demo, model subscription or hosted service.

The [November 13 report](2026-11-13-source-candidate.md) and
[November 9 report](2026-11-09-source-candidate.md) preserve earlier evidence and
the unresolved items as they stood on those dates. They are historical reports,
not the current publication checklist.
