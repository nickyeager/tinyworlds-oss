# v0.1.1: local installation and contributor checks

This maintenance update improves the public source installation. It does not
change the supported generation matrix: local Codex + Godot remains the
developer-preview target.

## Changes

- Setup installs constrained Python dependencies, frozen frontend dependencies
  and Chromium. A new `.env` receives a unique signing key with owner-only
  permissions. Existing configuration and databases are preserved.
- Startup binds to loopback, configures both sides for custom ports, and stops
  only process groups it started. It no longer migrates databases, suppresses
  migration errors, enables backend reload, or kills arbitrary port owners.
- The local diagnostic checks application prerequisites without printing secrets
  or contacting providers. It labels generation prerequisites separately.
- Contributors can refresh the source manifest from tracked files. CI checks
  exact tracked coverage, source hashes and public Markdown links.
- A new CI job installs from a clean checkout, requests the real backend health
  endpoint and frontend create page, and verifies both ports close on shutdown.

## Verification and limits

Five real filesystem/socket/process checks passed locally: unique private keys,
existing configuration/database preservation, symlink preservation, occupied-port
safety, and recognition of the installed Node version. The first installer run
exposed a version-parser bug with Node's `v` prefix; it was corrected and the
installer completed successfully on rerun.

The installed launcher served a healthy API and the frontend create page on
custom loopback ports, then released both ports on shutdown. These checks ran
in an isolated macOS arm64 checkout. Existing local previews were not restarted.

No new game generation, provider login, mobile gameplay, hosted deployment or
container distribution was tested for this maintenance change. The startup
check verifies HTTP readiness, not a browser click-through or model quality.
See the [CI runs](https://github.com/nickyeager/tinyworlds-oss/actions) for the
Linux installation and application checks on the published revision.
