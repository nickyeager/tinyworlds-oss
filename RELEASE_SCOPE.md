# Source distribution scope

This source snapshot has no inherited Git history. It includes current application code, tests and required runtime guidance. Private data, generated games, recordings, internal research, production runbooks and automatic deployment workflows are omitted.

Optional development skills/templates with unresolved provenance are omitted from this distribution only; the development checkout and skill-audit records are preserved. Their omission is not an effectiveness verdict. Audio integration fixtures are also omitted pending asset review.

The supported preview scope is local Codex + Godot. See docs/releases/v0.1-developer-preview.md for release status, verification evidence and limitations. Preparing this snapshot does not publish it or certify security or third-party rights.
